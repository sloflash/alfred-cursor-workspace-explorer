# Alfred Cursor Workspace Explorer

Alfred workflow to search, explore and open Cursor workspaces. 

> Screenshots coming soon! The workflow allows you to:
> - Browse your Cursor workspaces in Alfred
> - Search through workspace directories with fuzzy matching
> - Quickly open workspaces in Cursor
> - Navigate through nested workspace folders

## Requirements

* Python 3
* Cursor

## Setup

Define path (`workspaces_home`) where Cursor workspaces are stored. The workflow also supports subdirectories in your Cursor Workspace folder.

Set `workspaces_home` e.g. to /Users/username/cursor-workspaces

## Features

* Search and browse Cursor workspaces
* Open workspaces directly in Cursor
* Support for nested workspace directories
* Quick navigation with Alfred's fuzzy search

## Usage

1. Trigger the workflow with `curw` in Alfred
2. Browse through your workspace directories
3. Press Enter to open a workspace in Cursor
4. Use ⌘ (Command) key to reveal files in Finder
